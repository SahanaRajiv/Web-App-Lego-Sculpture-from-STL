How to Use This App

Transform your 3D models into buildable LEGO creations!

1 Upload Your STL File

Select an STL file from your computer or choose from previously uploaded files. STL is a common 3D model format used in CAD software and 3D printing.

2 Configure Options

Number of Layers (10-100)

Controls the resolution of your LEGO model. More layers = more detail but more bricks needed.

Direction (X, Y, Z)

Choose which axis to slice the model along. Z is typically "up" for most models.

Make Model Hollow

Creates a shell version of your model to save bricks. Great for larger builds!

Overlay Layers

Shows the previous layer as a faded guide in each layer image. Helps with building!

Create PDF Instructions

Generates a downloadable PDF booklet with assembly instructions for each layer.

Color Bricks by Shape

Different brick sizes get different colors in the instructions for easy identification.

Remove Hanging Bricks

Ensures every brick has support below it. Recommended for solid (non-hollow) models.

3 Click Convert

The app will process your model and generate:

  • PDF instructions - Printable layer-by-layer assembly guide with brick counts
  • 3D brick model - Downloadable STL of the LEGO version

4 Build Your Creation!

Follow the layer-by-layer instructions to build your LEGO masterpiece. Start from layer 0 (the bottom) and work your way up!
